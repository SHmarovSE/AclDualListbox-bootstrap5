# 🔐 AclDualListbox (Bootstrap 5)

**AclDualListbox** — это монолитный виджет на базе **Bootstrap 5**, спроектированный для удобного и наглядного управления правами доступа (ACL — Access Control List). Компонент реализует механику перемещения элементов между двумя панелями: доступными экшенами (сгруппированными в раскрывающееся дерево `<details>`) и назначенными правами (в виде плоского списка).

Виджет полностью изолирует внутреннюю DOM-структуру, поддерживает умное кэширование элементов, предоставляет динамическую систему счетчиков сессии, визуально отслеживает добавленные элементы с маркером `(новое)` и бережно очищает память через встроенный деструктор.

---

## 🚀 Основные возможности

* **Древовидная группировка слева:** Автоматическая группировка доступных экшенов по категориям на базе нативного HTML5-тега `<details>`.
* **Интеллектуальный поиск:** Быстрый поиск по названию или описанию экшена с автоматическим раскрытием папок (`open="true"`), содержащих совпадения.
* **Информативная панель счетчиков:**
  * `Доступно` — Количество оставшихся экшенов в левом дереве в реальном времени.
  * `Выбрано` — Текущие выделенные элементы (`.bg-light`) в левом дереве.
  * `Загружено` — Базовое состояние прав роли, пришедшее с сервера при инициализации.
  * `Добавлено` — Количество новых прав, перенесенных в рамках текущей сессии.
* **Визуальные маркеры:**
  * **Синий маркер-точка** на элементе `<summary>`, если папка свернута, но внутри неё есть выделенные экшены.
  * **Зеленый маркер `(новое)`** на плашках в правой панели, если они были перенесены в рамках текущей сессии.
* **Массовые операции:** Поддержка кнопок «Перенести все видимые», «Очистить все», а также мгновенный перенос элементов по двойному клику (`dblclick`).

## 🛠 Установка и подготовка

### Подключение через CDN (jsDelivr)

Вы можете подключить последнюю стабильную версию виджета напрямую к вашему проекту:

```html
<!-- Подключение JavaScript-модуля компонента -->
<script src="https://cdn.jsdelivr.net/gh/SHmarovSE/AclDualListbox-bootstrap5@latest/AclDualListbox.js"></script>
```

## ⚙️ API Компонента (Конструктор и Опции)

Виджет инициализируется как стандартный ES6 класс:

```javascript
const widget = new AclDualListbox(containerSelector, options);
```

* **`containerSelector`** *(String)*: Селектор пустого контейнера в DOM (например, `'#acl-widget-container'`), куда внедрится монолитная Bootstrap-карточка.
* **`options`** *(Object)*: Настройки конфигурации виджета.

### Конфигурация `options` (По умолчанию)

```javascript
{
  showSearch: true,             // Отображать ли строку быстрого поиска (true/false)
  entityParamName: 'entity_id', // Имя POST/GET параметра сущности (например, role_id)
  leftLabel: '',                // Текст основного заголовка левой панели
  rightLabel: '',               // Текст основного заголовка правой панели
  urls: {
    available: '',            // URL для загрузки доступных прав роли
    assigned: '',             // URL для загрузки уже назначенных прав роли
    save: ''                  // URL для POST-отправки измененных данных
  },
  mapping: {                    // Правило маппинга полей из JSON бэкенда
    id: 'id',                 // Ключ уникального ID экшена
    name: 'name',             // Ключ системного имени/названия экшена
    description: 'description',// Ключ текстового описания экшена
    group: 'group'            // Ключ названия группы (категории)
  },
  onSelectEntityClick: (updateWidget) => {
    // Коллбэк для внешней кнопки "Выбрать..." (например, вызов модалки со списком ролей)
    // Передает функцию updateWidget({id, label}) наружу для триггера загрузки данных
  }
}
```

## 📊 Структура входных данных (JSON)

Бэкенд должен отдавать данные в формате массива объектов (либо объекта с ключом `items`). Поля объектов должны строго соответствовать правилам, указанным в `options.mapping`.

**Пример ответа сервера для `urls.available` (Левая панель):**

```json
[
  { 
    "id": 10, 
    "name": "login", 
    "description": "Авторизация пользователя", 
    "group": "Экшены авторизации" 
  },
  { 
    "id": 11, 
    "name": "logout", 
    "description": "Выход пользователя", 
    "group": "Экшены авторизации" 
  },
  { 
    "id": 24, 
    "name": "get_assigned_actions_for_role", 
    "description": "Возвращает список назначенных действий для роли", 
    "group": "Работа с классом SqlFormBuilder" 
  }
]
```

## 💻 Пример интеграции на странице

Полный цикл подключения виджета, включая вызов внешней логики для выбора сущности (например, роли «Пользователь»):

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Управление правами доступа (ACL)</title>
    <!-- Подключаем Bootstrap 5 и Bootstrap Icons -->
    <link href="https://jsdelivr.net" rel="stylesheet">
    <link href="https://jsdelivr.net" rel="stylesheet">
</head>
<body class="bg-light p-4">

    <!-- Целевой контейнер для виджета -->
    <div id="my-acl-container" style="max-width: 1100px; margin: 0 auto;"></div>

    <!-- Подключаем наш JS-модуль -->
    <script type="module">
        import { AclDualListbox } from './js/globalimport/AclDualListbox.js';

        // Инициализируем виджет
        const aclWidget = new AclDualListbox('#my-acl-container', {
            showSearch: true,
            entityParamName: 'role_id',
            leftLabel: 'Доступные действия для роли:',
            rightLabel: 'Назначенные права:',
            urls: {
                available: '/api/acl/get-available-actions.php?action=list',
                assigned: '/api/acl/get-assigned-actions.php?action=list',
                save: '/api/acl/save-role-permissions.php'
            },
            mapping: {
                id: 'id',
                name: 'name',
                description: 'description',
                group: 'group'
            },
            onSelectEntityClick: (updateWidget) => {
                // Пример: Эмуляция выбора роли во внешней модалке / кастомном селекте
                setTimeout(() => {
                    const selectedRoleFromModal = {
                        id: 3, 
                        label: 'Выбрана роль: Пользователь'
                    };
                    
                    // Передаем данные обратно в виджет. Он сам снимет оверлей и запустит loadData()
                    updateWidget(selectedRoleFromModal);
                }, 300);
            }
        });
    </script>
</body>
</html>
```

## 🛠️ Архитектура внутренних методов

Разделение логики на атомарные специализированные методы исключает хаос при масштабировании компонента:

### ⏱️ Инициализация и события
* **`init()`** — Генерирует базовый HTML-каркас виджета, включая блокирующий оверлей стартового состояния, шапку с кнопками управления, строку поиска и разметку строки счетчиков.
* **`cacheElements()`** — Кэширует ссылки на ключевые элементы DOM (кнопки, панели, счетчики) в системный объект `this.elements` для исключения повторных тяжелых вызовов `querySelector`.
* **`bindEvents()`** — Навешивает делегированные слушатели кликов (`click`), двойных кликов (`dblclick`) для мгновенного переноса и событие `input` на строку поиска.

### 🔄 Загрузка и Рендеринг (Data Flow)
* **`loadData(entityId)`** — Асинхронный конвейер. Параллельно делает запросы к двум эндпоинтам и включает спиннеры. При возникновении ошибки на любой из панелей полностью блокирует интерфейс и выводит кастомный блок ошибки.
* **`renderAssigned(items)`** — Отрисовывает плоский список справа. Фиксирует начальный счетчик *Загружено* на базе `items.length`.
* **`renderAvailable(items)`** — Метод группировки. Формирует структуру `<details>` и плашки доступных экшенов слева. Если экшен уже есть в списке назначенных прав, скрывает его с помощью класса `d-none`.

### 📈 Управление счетчиками и маркерами сессии
* **`updateLeftCounters()`** — Пересчитывает видимые экшены слева (*Доступно*) и выделенные элеметы `.bg-light` (*Выбрано*). Сканирует группы: если в свернутом `details` есть активные выделения, автоматически внедряет в элемент `<summary>` синюю точку-маркер `.acl-group-marker`.
* **`updateRightCounters(initialCount)`** — Управляет правой панелью. Фиксирует базовое число, а также динамически считает элементы с классом `.acl-item-new` для вывода значения в счетчик *Добавлено*.
* **`collapseAllGroups()`** — Метод-утилита для кнопки «Свернуть все». Быстро убирает атрибут `open` у всех контейнеров `.acl-group` на левой панели.

### 🚚 Логика перемещения элементов
* **`moveItems(items, direction)`** — Универсальный шлюз перемещения элементов.
  * При `direction === 'right'`: скрывает оригиналы файлов слева (`d-none`), создает глубокую копию `cloneNode(true)`, вешает класс `.acl-item-new`, активирует скрытый тег `(новое)` и пушит элемент в правую панель. Удаляет заглушку `.acl-placeholder` («Нет назначенных прав»).
  * При `direction === 'left'`: удаляет копию справа, убирает ID из структуры `Set`. Если элемент соответствует текущему поисковому запросу, возвращает ему видимость слева. Если правая панель полностью опустела, возвращает безопасную заглушку `.acl-placeholder`.

## 🧹 Управление памятью (Сброс виджета)

Для предотвращения утечек памяти (**Memory Leaks**) при динамической смене страниц или перезагрузке модулей в SPA-приложениях, класс укомплектован полноценным деструктором **`destroy()`**.

При вызове метода виджет полностью вычищает себя из памяти:
```javascript
aclWidget.destroy();
```

**Что делает метод внутри:**

1. Снимает тяжелые ссылки на внешние функции обратного вызова (`this.options.onSelectEntityClick = null`).
2. Очищает и сбрасывает внутреннюю коллекцию идентификаторов `Set` (`this.assignedIds.clear()`).
3. Итерируется по объекту кэша `this.elements` и принудительно зануляет все ссылки на крупные DOM-узлы, разрывая циклические зависимости в оперативной памяти.
4. Вызывает нативный метод `.remove()` на корневом элементе карточки виджета, физически уничтожая его разметку со страницы.
